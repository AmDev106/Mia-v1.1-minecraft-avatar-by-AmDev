Mia is a red haired and almost fully nude custom character I animated and modeled in Customizable Player Models mod. She is not based on any real person or fictional characters, I wrote her character myself and designed her off of things just think are cool, like red hair, pony tails, green eyes, subtle emo/goth elements.

Installation instructions
- If you haven't already, download and install the Modrinth App and link your Minecraft account, and create a GitHub account.
- If you already have an instance with a supported CPM version and mod loader, you can skip this step. 
Tap the plus sign to create a new instance, select a mod loader (preferably Fabric), and select a Minecraft version that can be found in the CPM supported versions page which is almost every major Minecraft version.
- Open your instance, click "Browse Content" and search for "Customizable Player Models" mod and install it. If no mod shows up, then you probably either aren't using a supported mod loader or Minecraft version!
- If it is a new instance, go back to your instance and run it once to generate the "player_models" and "skins" folders in the file directory of your instance. Leave the game, click the three dots in the top right of your instance page, click open folder which should open your file explorer, open another file explorer window and go to your downloads.
- Download the latest version of my mod from the files page.
- It is crucial that you follow these steps exactly: Open the folder you downloaded earlier and drop the file, "mia_by_amdev106..." (the .cpmproject file) into "player_models." and now move "vanilla_mia" and "sfwvanilla_mia" (the .png images) into "skins" and you can close your file explorer. (If it gives you the option to, replace the file in destination) NOTE: if these folders don't exist you can simply create them in your instance directory with the exact same titles.
- We're almost done! now we have to equip our skin. Run your instance and when you see the title, in the top left press "Open Skin Editor." Now in the top left you will click "File" then "Load" and a menu should pop up in the center of your screen. In that menu open "player_models" and click "mia_by_amdev106..." and then "Ok."
These next couple steps are kind of confusing but important for players on the server that don't have the CPM mod installed:
- Now you should see the skin in the editor, now we have to export it so you can play as it in game and so that other people with the mod can see it! Click "File" again and this time click "Export." and make sure "Export mode" is set to "skin." Check the box that says "Slim (Alex)" and click "Change vanilla skin." You should see a new menu, click "Open Skin." From here open the "skins" folder and click "vanilla_mia" (or sfw version so public servers wont ban you for nsfw skins) and click "Ok." 
- It should prompt you to add skin to list, I would click "Cancel." as it may change with future updates. Now click "Select Skin" and we have the vanilla skin set up over!
- Click "Export & Upload," then click "Ok" on the prompt, click the "Upload Gist" tab.
Here is where you need that GitHub account:
- (If you've used this mod before and are updating, the gist you have already made) Now open your browser and go to GitHub to make sure your logged in. Now go to GitHub Gists to create a new gist. 
-Back in Minecraft, Under "Please create a GitHub Gist with the following text" click "copy."
-In your browser, go to your gist, copy the text next to the "1" and now click "Create Secret Gist." This will upload that string of code to GitHub servers. You should now be viewing your Gist. Copy the address from your browser's address bar, go back to Minecraft, and paste it in the box under "And paste it's URL here." Now simply press "Ok." 
And that's it!!!
You can now safely close the editor. and if your skin isn't showing up in game, re-launch Mnecraft, wait a couple minutes, or check your internet. If nothing is working PLEASE report it in Issues because I know how annoying it is when stuff like this happens and devs don't respond. I will try to get back with you as soon as possible!
